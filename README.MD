# Auth Server - Rust
 
This is a simple authentication server in Rust for personal use. Is intended to be used as a reference for learning Rust. Also is used as a playground for learning how to build authentication methods from scratch.

## Features

- [x] Register and login with email and password
- [x] Link and login with passkeys
- [x] JWT tokens
- [ ] Refresh tokens
- [ ] Register and login with TOTP
- [ ] Register with External Providers

### Technologies

This server is built with Rust and axum. Uses SQLite for persistence.
